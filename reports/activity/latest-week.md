## Coverage and limitations

- Collection window: 2026-08-25T20:14:51.558Z to 2026-11-23T20:14:51.558Z (90 day lookback).
- Commit history (owned repositories): partial (page-cap).
- Pull requests (owned repositories): partial (page-cap).
- Issues (owned repositories): partial (page-cap).
- Issue and review comments (owned repositories): partial (page-cap).
- Releases (owned repositories): ok.
- Workflow runs (bounded set): ok.
- Public contribution events: ok.
- Authored issues and pull requests outside owned repositories: ok.
- Authored commits outside owned repositories: ok.
- GitHub's public event feed exposes at most 300 events and roughly 90 days of history; older activity is not claimed.
- Repository metadata changes are detected by diffing weekly snapshots, so their exact time is unknown and they are marked "observed-at".
- Dependabot and security alerts are not public data and are excluded from the published dataset.
- Pull request reviews are collected from the public event feed only; review history beyond the feed window is not claimed.
- Activity is collected for a bounded set of active repositories, not every repository in the catalogue.
- Repository activity is collected for the bounded candidate set only; absence of an event does not prove absence of work.
- Routine commit detail is retained for 30 days; pull requests, issues, reviews, and releases are retained for the full lookback window.
